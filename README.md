# -# 浮窗时间工具

一个极简、可置顶的 Windows 悬浮时间工具。默认显示大号实时 `HH:mm:ss`，所有操作都通过右键菜单完成。

## 运行

双击 `FloatingTimeTool.exe` 即可使用，无需安装。

适用于 Windows 10/11。程序可单独复制或分享；首次运行会将内部资源和设置保存到用户自己的 `%LocalAppData%\FloatingTimeTool`，不会在 EXE 同目录生成辅助文件。

> EXE 未进行数字签名。如果 Windows 显示安全提示，请在确认来源可信后选择继续运行。

## 功能

- **实时时间模式**：默认模式，以大号 `HH:mm:ss` 显示当前时间，不显示年月日。
- **倒计时模式**：支持 5、10、25、45、60 分钟预设及自定义时长。
- **正计时模式**：支持开始、暂停、继续和重置，不触发到点提醒。
- **到点提醒**：倒计时结束后数字变红；可播放约 3 秒的尖锐提示音，每次连续播放 3 遍，并可设置超时后的重复提醒间隔。
- **颜色自定义**：可选白、红、琥珀、绿、青等预设，或打开系统调色盘选择任意数字颜色；到点状态始终为红色。
- **悬浮窗口**：可置顶、拖动、缩放、最小化；数字会随窗口大小自适应缩放。
- **状态记忆**：时长、模式、颜色、提醒设置、窗口位置和大小会自动保存。

## 右键菜单

在窗口任意位置右键打开菜单：

- 开始/暂停/继续或重置当前计时。
- 切换 **实时时间 / 倒计时 / 正计时** 模式。
- 设置倒计时时长与数字颜色。
- 在倒计时或正计时模式中显示/隐藏顶部实时时间。
- 开关声音、视觉提醒，设置超时重复提醒间隔和始终置顶。
- 最小化或退出程序。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Space` | 开始、暂停或继续计时 |
| `Ctrl + R` | 重置当前计时 |
| `Ctrl + P` | 切换窗口置顶 |

## 自定义倒计时

选择右键菜单中的“设置倒计时 → 自定义…”，可输入：

- `90`：90 秒
- `25:00`：25 分钟
- `01:25:00`：1 小时 25 分钟

## 窗口大小

默认窗口尺寸为 `260×160`。拖动窗口任意位置可移动，拖动右下角可缩放。

当倒计时或正计时模式显示顶部实时时间时，程序会自动提高最小高度，避免信息重叠。

## 设置与提示音

程序运行资源、设置文件和提示音位于：

```text
%LocalAppData%\FloatingTimeTool
```

如需恢复初始设置，可关闭程序后删除该文件夹。若要替换提示音，可用同名 WAV 文件替换其中的 `sharp-alert.wav`。

## 分享

分享时只需要发送 `FloatingTimeTool.exe`。对方首次打开时会自动生成其自己的本地设置与内部资源，不会影响你的设置。
